## 📌 What is Matplotlib?

**Matplotlib** is a Python library used to create graphs and visualizations from data.

It helps us understand data visually through charts such as:

* 📈 Line plots
* 📊 Bar charts
* 🔵 Scatter plots
* 📉 Histograms
* 🥧 Pie charts
